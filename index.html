Safe-by-design public sleeping infrastructure

One clean, safe overnight sleeping cell, recessed in a wall. When idle it retracts flush and moves the sleeping surface into a hidden bay to be automatically cleaned.

An open-source hardware project. A powered machine that must fail safe around a sleeping, vulnerable person — so safety is the first design constraint, worked in the open.

View the project on GitHub How to help

A single moving part — a true syringe

A piston slides inside a fixed tube. Retracted, its face is the floor and back of an open sleeping capsule. Advanced, its own face becomes the flush public wall — there is no separate door. The same sweep clears the cell and seals it on the hidden service side for cleaning.

Priorities, in order: vandal resistance, hygiene, reliability, low maintenance, low energy, low cost, simplicity, easy servicing, long life. Comfort is deliberately low priority.

Safety is the whole problem

This machine moves a powered steel piston through a space a person occupies — and users are assumed vulnerable (asleep, intoxicated, unwell) and unable to self-rescue. The design principle is PREVENT (never move while occupied) → REACT (stop & reverse on contact) → fail safe. “Push the occupant out” is not a mode the machine can enter.

Safety functionApproach
SF1 — Occupancy detectionDiverse-redundant suite (radar vitals + thermal + CO₂ + load/BCG), fail-safe voting, target ISO 13849 PL e. Any presence or any sensor fault ⇒ assume occupied.
SF2 — Contact-force capIndependent force-limit trip that stops and reverses the sweep — works even if SF1 is blind.
SF3 — Wiper sealFills the running gap and scrapes the bore clean each sweep (hygiene + gap-safety).
SF4 — Fail-open driveBack-drivable, with a return spring that biases the pod open — power loss relieves a trapped occupant.
SF5 — Soft motion + signallingGentle velocity profile and clear state lights (ready / moving / closed / alarm).

Honest status: this is design and first-order simulation only — no built hardware, no physical validation, and no safety certification yet. It is published as research to be scrutinised and built upon, not deployed. See the safety notice in the repository.

Built in the open

Every design decision is recorded as an ADR, the mechanism is parametric CAD (the source of truth), and the safety logic is a real, headless-testable state machine — its core invariant (the sweep never advances while life is detected) is enforced by a self-test that gates every push.

How to help

This is a solo, open project. The fastest way to move it forward is hands and scrutiny — most of the next steps need a workbench, not a budget.

Measure the seal drag

The single biggest unknown, and a ~$200 bench test. It unblocks the actuator, spring, and drive decisions. A fully-specified procedure is in the repo — the top first contribution.

Review the safety case

Independent eyes on the FMEA and the five safety functions. If you work in machine safety or ISO 13849, your read is invaluable.

Prototype SF1 sensing

Help breadboard the diverse-redundant occupancy suite — radar vitals, thermal, CO₂, load/BCG — the primary safeguard.
